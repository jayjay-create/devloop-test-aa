# Domain

- Glossary: `CONTEXT.md` at the repository root. Terms go in the moment they come up, not collected later.
- Decision records: `docs/adr/`.

## When to write a decision record

Write one only when all three hold:

1. Hard to reverse.
2. Surprising without explanation.
3. The result of a real trade-off.

## Format

- Title
- Context
- Decision
- Binding consequences
- Status — only for superseded or deprecated
- Rejected options — only when the rejection is not obvious
- One line: "What would make this decision invalid"
